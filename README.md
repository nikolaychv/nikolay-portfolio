# Featured Project

## Mechano

**Mechano** is a vehicle maintenance platform designed to connect vehicle owners with automotive repair shops.

The project was developed as a practical implementation related to my Master's thesis about the digital transformation of vehicle maintenance services.

The goal of the platform is to improve the way customers discover repair shops, book services, manage service information, and interact with automotive service providers.

### Main Features

- User management
- Repair shop management
- Repair shop service types
- Car brand management
- Booking management
- Booking status tracking
- Reviews and ratings
- Favorites
- User consent management
- Authentication
- Authorization
- Role-based access
- JWT authentication
- Swagger API documentation

### User Roles

- Client
- Service Owner
- Administrator

### Backend Technologies

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- PostgreSQL
- Liquibase
- Maven
- Docker
- Swagger / OpenAPI
- JUnit
- Mockito
- MapStruct
- Lombok

### Architecture

The backend follows a layered architecture with separation between:

- Controllers
- Services
- Repositories
- Entities
- DTOs
- Mappers
- Validation
- Exception handling
- Security configuration

Authentication is handled through a dedicated authentication service using JWT tokens.

# Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/nikolaychv/portfolio.git
```

Enter the project directory:

```bash
cd portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the application in your browser:

```text
http://localhost:3000
```

---

# Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
